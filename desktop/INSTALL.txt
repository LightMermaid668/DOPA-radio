DOPA-radio デスクトップアプリ インストール方法（macOS）
=====================================================

このアプリは無料配布のため Apple の署名・公証（Notarization）を行っていません。
そのため、ブラウザでダウンロードすると「壊れているため開けません」と表示される
ことがあります。以下のいずれかの方法で開けます。

--------------------------------------
■ 方法1: ターミナルで一発（おすすめ）
--------------------------------------
1. ダウンロードした .dmg を開き、DOPA-radio を「アプリケーション」フォルダへドラッグ
2. ターミナルを開いて次を実行:

   xattr -cr /Applications/DOPA-radio.app

3. アプリをダブルクリックで起動できます（次回以降もそのまま起動OK）

--------------------------------------
■ 方法2: ダウンロード時点で隔離しない
--------------------------------------
GitHub CLI でダウンロードすると隔離属性が付かず、そのまま開けます:

   gh run download <Run ID> -n dopa-radio-mac -D ~/Downloads/dopa-build
   cd ~/Downloads/dopa-build
   # 出てきた .dmg を開いてアプリをドラッグ

--------------------------------------
■ 方法3: 右クリックで開く
--------------------------------------
Finder でアプリを右クリック →「開く」→ もう一度「開く」
（macOSのバージョンによってはこれでも開けない場合があります）

--------------------------------------
■ うまくいかないとき
--------------------------------------
・「壊れている」が出続ける → 方法1の xattr -cr を実行してください
・Intel Mac の場合 → arm64ビルドは動きません。universal ビルドが必要な旨を
  開発者に伝えてください
・起動はするが画面が出ない → 少し待つ（初回はサーバー読み込みがあります）

Windows版について
-----------------
.zip 版は解凍して DOPA-radio.exe を実行するだけで動きます。
セットアップ版(.exe)は SmartScreen の警告が出たら「詳細情報」→「実行」を選んでください。
